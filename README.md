KÖK is a domain-specific language inspired by Turkic mythology.
The name comes from the Old Turkic word “Kök”, meaning Sky — symbolizing origin and transformation.

KÖK aims to simplify Unreal Engine development by allowing developers to write in a simpler syntax and transpile it into Unreal Engine compatible C++ code.

Project is currently in early development.

🇹🇷

KÖK, adını Eski Türkçede “Gök” anlamına gelen Kök kelimesinden alır.
Yaratım ve dönüşüm fikrini temsil eder.

KÖK, Unreal Engine geliştirmeyi daha sade bir dil aracılığıyla kolaylaştırmayı ve yazılan kodu Unreal uyumlu C++’a dönüştürmeyi hedefler.

Proje şu anda geliştirme aşamasındadır.
