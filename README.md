# K-K
KÖK is a DSL inspired by Turkic mythology. Its name comes from the Old Turkic word “Kök” (Sky), symbolizing origin and transformation. It transpiles simple syntax into Unreal Engine compatible C++ code.  KÖK, adını Eski Türkçede “Gök” anlamına gelen kelimeden alır ve sade yazılan kodu Unreal uyumlu C++’a dönüştürür.
